# Codebase Audit

that accidentally scanned the local virtual environment and several reports
contained encoding-error output instead of valid findings. They were removed
during the 2026 reliability hardening effort rather than left in-tree as
misleading evidence; their history remains available in Git.

The current evidence-backed audit is maintained under:

- `docs/reliability-hardening/PLAN.md`
- `docs/reliability-hardening/VERIFICATION.md`
- `docs/reliability-hardening/WINDOWS-VERIFICATION.md`
- `docs/reliability-hardening/FINAL-REPORT.md` (created at final verification)
